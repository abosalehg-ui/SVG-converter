## 📌 نظرة عامة

هذا المشروع يقدم **نسختين** من محول الصور إلى SVG:

| النسخة | الملف | الوصف |
|--------|-------|-------|
| 🖥️ **تطبيق سطح المكتب** | `svg_converter.py` | تطبيق Python بواجهة Tkinter |
| 🌐 **تطبيق الويب** | `index.html` | يعمل مباشرة في المتصفح |

خوارزمية التحويل واحدة ومشتركة بين النسختين (`svg_core.py` و `svg-core.js`)،
ويضمن [اختبار تكافؤ](tests/fixtures/README.md) في الـ CI أنهما تنتجان **نفس
الملف بايتاً ببايت** لنفس المدخلات.

## 🔒 الخصوصية

**لا تُرفع صورك إلى أي خادم.** كل المعالجة تتم داخل جهازك:

- تطبيق الويب لا يُجري أي طلب شبكة إطلاقاً، وسياسة `Content-Security-Policy`
  في `index.html` تفرض `connect-src 'none'` — أي أن المتصفح نفسه يمنع أي
  إرسال، وليست مجرد وعداً في التوثيق.
- تطبيق سطح المكتب يعمل محلياً بالكامل.

### 🎨 أوضاع التحويل

| الوضع | الوصف | الاستخدام الأمثل |
|-------|-------|------------------|
| 🎨 **ملون** | الحفاظ على الألوان الأصلية | صور فوتوغرافية، رسومات ملونة |
| ⬛ **أبيض وأسود** | ثنائي بحت — لا درجات رمادية في الناتج | شعارات، أيقونات، توقيعات |
| 🌫️ **تدرج رمادي** | درجات الرمادي | صور فنية، رسومات بالقلم |

### 🎛️ خيارات التحكم

| الخيار | النطاق | التأثير |
|--------|--------|---------|
| 🎨 مستويات الألوان | 2 - 6 | عدد الدرجات لكل قناة لون. الناتج = المستويات³ لوناً (٨ إلى ٢١٦) |
| 📊 دقة التفاصيل | 1 - 10 | حجم المربّع: ١ = مربعات ١٠×١٠ بكسل، ١٠ = بكسل واحد |
| 📐 مقياس الإخراج | 50% - 200% | تكبير أو تصغير الناتج |

> ℹ️ **ملاحظة:** الخيار كان سابقاً "عدد الألوان (2-64)" لكن معظم نطاقه لم يكن
> يؤثر على الناتج فعلياً. صار الآن يتحكم مباشرةً بعدد المستويات، وكل قيمة من
> ٢ إلى ٦ تعطي نتيجة مختلفة.

## 🖥️ تطبيق سطح المكتب (Python)

### 📋 المتطلبات

```bash
pip install -r requirements.txt      # Pillow فقط
```

#### المكتبات الاختيارية

```bash
pip install numpy       # تسريع التحويل ٣-١٢ ضعفاً (يعمل بدونها بسرعة أقل)
pip install pypotrace   # تتبّع بمنحنيات بيزييه للوضع الأبيض والأسود
pip install cairosvg    # لعرض ملف SVG الحقيقي في لوحة المعاينة
```

بدون `cairosvg` تعرض لوحة المعاينة الصورة النقطية المفلترة — وهي **تقريب**
للناتج وليست الناتج نفسه، ولذلك يتغيّر عنوان اللوحة إلى «معاينة تقريبية».

### 🚀 التشغيل

```bash
git clone https://github.com/abosalehg-ui/SVG-converter.git
cd SVG-converter
python svg_converter.py
```

### ⚠️ ملاحظة حول العربية في Tkinter

الواجهة مرتّبة من اليمين إلى اليسار وتختار تلقائياً خطاً يدعم العربية من
النظام. لكن Tk **لا ينفّذ تشكيل الحروف العربية (Arabic shaping) ولا خوارزمية
bidi على كل المنصات** — على لينكس تحديداً قد تظهر الحروف منفصلة. هذا قيد في
Tk نفسه لا في التطبيق. إن كان عرض العربية مهماً، استخدم تطبيق الويب.

### 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---------|-----------|
| **Python 3.9+** | لغة البرمجة |
| **Tkinter** | واجهة المستخدم الرسومية |
| **Pillow** | فتح الصور ومعالجتها |
| **NumPy** *(اختياري)* | تسريع حساب متوسط المربعات |
| **pypotrace** *(اختياري)* | تتبّع المسارات للوضع الأبيض والأسود |
| **cairosvg** *(اختياري)* | تصيير SVG في لوحة المعاينة |

## 🌐 تطبيق الويب

### 🚀 التشغيل

```bash
# أونلاين
https://abosalehg-ui.github.io/SVG-converter/

# أو محلياً — افتح الملف مباشرة
open index.html      # macOS
start index.html     # Windows
```

عند الفتح بـ `file://` يمنع المتصفح تشغيل Web Worker، فيرجع التطبيق تلقائياً
للخيط الرئيسي. الوظائف كلها تعمل، لكن الواجهة قد تتجمّد لحظياً على الصور
الكبيرة. لتجربة كاملة شغّل خادماً محلياً: `python -m http.server`.

### ⌨️ اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|----------|---------|
| `Ctrl/⌘ + O` | فتح اختيار ملف |
| `Ctrl/⌘ + Enter` | تشغيل التحويل |
| `Ctrl/⌘ + S` | تحميل ملف SVG الناتج |
| `Ctrl/⌘ + D` | تبديل الوضع الفاتح/الداكن |

> `Ctrl+S` لا يعطّل اختصار المتصفح إلا عندما يكون هناك ملف جاهز للتحميل فعلاً.

### 🌓 الوضع الداكن

زر تبديل في أعلى الصفحة يحفظ تفضيلك في `localStorage` ويحترم `prefers-color-scheme`.
كل ألوان الثيم معرّفة مرة واحدة بدالة `light-dark()` في `styles.css`.

### ♿ إمكانية الوصول

- **تباين مُتحقَّق منه:** كل عنصر نصي مرئي يحقق WCAG AA (4.5:1) في الوضعين.
- عناصر تحكم أصلية (`<input type="radio">`) لتنقّل الأسهم الطبيعي.
- `<fieldset>` / `<legend>` لمجموعات الخيارات.
- رابط «تخطّي إلى المحتوى» يظهر فعلياً عند التركيز عليه.
- نص بديل (`alt`) على كل صور المعاينة.
- `aria-live` لرسائل الحالة و `role="progressbar"` لشريط التقدم.
- احترام `prefers-reduced-motion`.

### 🛡️ الحدود والأمان

- الحد الأقصى للصورة **40 ميجابكسل**، وللناتج **40 ميجابكسل** أو 16384 بكسل
  لكل بُعد — تجاوزها يعطي رسالة واضحة بدل إسقاط التبويب.
- معاينة الناتج تُعرض عبر `<img src="blob:">` لا عبر `innerHTML`، فلا يمكن
  تنفيذ أي كود مضمّن في SVG.
- تطبيق سطح المكتب يرفض «قنابل فك الضغط» (صور صغيرة تتمدد لجيغابايتات).

### 🛠️ التقنيات المستخدمة

| الملف | الدور |
|-------|-------|
| `index.html` | الهيكل و CSP |
| `styles.css` | التصميم والثيمات |
| `app.js` | منطق الواجهة |
| `theme-init.js` | تطبيق الثيم قبل أول رسم (منع الوميض) |
| `svg-core.js` | خوارزمية التحويل المشتركة |
| `svg-worker.js` | Web Worker للتحويل خارج الخيط الرئيسي |

## 🧪 الاختبارات والتطوير

```bash
pip install -r requirements-dev.txt

# اختبارات Python
pytest

# اختبارات JavaScript
node --test tests/svg-core.test.js tests/parity.test.js

# الفحص والتنسيق
ruff check .
ruff format .
```

### 🔄 اختبار التكافؤ

`svg_core.py` هو **المرجع**. عند تغيير الخوارزمية:

```bash
python tests/fixtures/generate_golden.py   # يعيد توليد الملفات الذهبية
pytest                                     # يؤكد تطابق Python
node --test tests/parity.test.js           # يؤكد تحديث JavaScript بالمثل
```

فشل أحد الجانبين دون الآخر = تباعُد بين النسختين. راجع
[`tests/fixtures/README.md`](tests/fixtures/README.md).

### CI تلقائي

| المهمة | ما تفعله |
|--------|-----------|
| `Python tests` | pytest على 3.9 / 3.11 / 3.12 + تغطية (svg_core مضمونة ≥95%) |
| `Lint (ruff)` | `ruff check .` و `ruff format --check .` على كامل الشجرة |
| `JavaScript tests` | node:test على 18 / 20 / 22 + فحص صياغة كل ملفات المتصفح |
| `Cross-language parity` | إعادة توليد الملفات الذهبية والفشل عند أي اختلاف |
